# JK Finance

Projeto de site para banco digital voltado a professores.

## Descrição do projeto
JK Finance é uma página web de apresentação para um banco digital destinado a professores. O projeto traz um layout responsivo com cabeçalho, navegação, seção de destaque, cards de serviços e elementos visuais pensados para desktop e mobile.

## Tecnologias usadas
- HTML
- CSS
- JavaScript
- FontAwesome (para ícones)

## Objetivo
O objetivo deste projeto é demonstrar a construção de uma interface web moderna e responsiva para um serviço financeiro. Ele serve como protótipo de um site institucional para um banco digital, com foco em:
- apresentação da marca
- navegação responsiva
- design visual com seções e cards
- experiência para desktop e mobile

## Estrutura do repositório
- `index.html` - página principal do projeto
- `style.css` - estilos e layout responsivo
- `sript.js` - arquivo JavaScript (atualmente sem código, preparado para interatividade)
- `IMAGENS/` - imagens usadas no site
- `LICENSE` - licença do projeto
- `TODO.md` - lista de tarefas e melhorias futuras

## Como usar
1. Abra o arquivo `index.html` no navegador.
2. Verifique o layout e a navegação.
3. Edite o conteúdo e os estilos conforme necessário.

## Observações
Este projeto é um protótipo visual e pode ser expandido com funcionalidades adicionais em JavaScript para formulários, animações ou navegação dinâmica.
